# Social Engineering Behavior Representation Layer

This directory currently contains the versioned, machine-readable SE-BRL codebook and its dependency-free Python loader and structural validator. It implements the hierarchy in Section 3.3.1, the evidence states and future encoding metadata in Section 3.3.2, the modality-support matrix in Table 4.4, and the processing boundaries in Sections 4.5.2-4.5.3 of the thesis manuscript.

`se_brl/codebook.v0.1.0.json` is the sole canonical runtime source for dimension and indicator IDs and names, parent mappings, dimension-level evidence boundaries and exclusions, evidence-state definitions, modality definitions and support codes, required-evidence rules, deterministic dimension order, vector-slot metadata, and the schema and codebook versions. Python code loads and validates that document rather than maintaining a second taxonomy.

Codebook version `0.1.0` is pre-1.0 and is not the final validated or fully frozen codebook. Finer per-indicator rules, examples, overlap handling, and evidence-reference formats remain deferred until the protocol-freeze stage.

SE-BRL is currently an instrument and schema, not a trained model. No behavior-identification model, calibrator, confidence, probability, performance result, vector value, final risk mechanism, or phishing classification is produced here. Existing extension results remain explicitly rule-based and are not generated by this package.

Dataset provenance and availability audits, annotation and reviewer validation, rule implementation, evidence records and locators, model training, calibration, E2/E3 vectors, controlled evaluation, and sealed-test work remain deferred.
